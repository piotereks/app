Dashboard

The Dashboard is the default screen when you open the app. It shows real-time free parking space counts for both monitored locations.

Parking Cards

Each location is shown as a parking card containing:

ElementDescription
Location nameGreenDay or Uni Wroc
Free spaces countLarge number showing currently available spaces
≈ indicatorShown when the value is approximated (interpolated from nearby data points)
Original valueShown in parentheses below the approximated value: (orig: 23)
Data ageSmall text showing how fresh the data is (e.g. 2m ago, just now)

Data Age Colour Coding

The free-spaces number changes colour based on how fresh the data is:

ColourMeaning
NormalData is fresh (< 5 minutes old)
Amber/orangeData is 5–15 minutes old
Red/fadedData is older than 15 minutes

Refresh

  • The app auto-refreshes every 5 minutes.
  • To refresh manually, click the ⟳ Refresh button in the header.

All Offline

If no live data can be retrieved, a banner is shown:

⚠️ All parking lots are offline. Showing last known data.
