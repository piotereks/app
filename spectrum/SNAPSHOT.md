## State notes

- No build system, package.json, tests, or lint config; Bootstrap CSS from CDN only.
- `audioSpectrum.js` implemented: custom radix-2 FFT + Hamming path, oscilloscope with linear/log/compand, spectrogram (history base 100 frames at the load-time canvas height, scaling proportionally with height up to 1000 frames so a maximized spectrogram shows more seconds at constant time-per-pixel density), log/linear axes with ticks, max-frequency range dropdown (full/24k/12k/6k/2k/1k/500/200/100, default 12k) for spectrum + spectrogram with dynamic FFT resolution: the analyser fftSize scales up to 32768 with the window (`2048 * nyquist / maxFreq`, min 2048) in both modes so narrow windows keep good resolution, and a ring-buffer (65536 samples from ScriptProcessorNode) FFT capped at `MAX_HR_FFT_SIZE = 32768` points pooled to display bins for windows ≤1k when "High-Res" is on (off by default; the toggle then only enables the ring-FFT path, recomputed every 2nd frame to limit CPU load),
- chart display resolution is tunable via consts: `DISPLAY_BINS = 1024` (all charts max-pool raw bins to this many display buckets; the "High-Res" toggle is a display preference, not analysis precision) and `MAX_HR_FFT_SIZE = 32768` (cap for the ring-buffer FFT size in points; lower = lighter CPU load); all tunable settings are named consts (`ANALYSER_FFT_SIZE`, `ANALYSER_MAX_FFT_SIZE`, `ANALYSER_SMOOTHING`, `DB_FLOOR`, `DB_LOG_EPSILON`, `DEFAULT_AVG_SECONDS`, `AVERAGE_UPDATE_MS`, `AVG_HISTORY_MARGIN`, `SMOOTH_WINDOW_LOG/LINEAR`, `MIN_SPECTROGRAM_FRAMES`, `AXIS_TICK_TARGET_PX`, `AXIS_TIME_TICKS`, `AMPLITUDE_TICKS`, `REC_TIMER_MS`, `FULLSCREEN_SETTLE_MS`, `URL_REVOKE_MS`, `MAX_INPUT_GAIN`, `GAIN_STEP`); the spectrum always draws as a single path (no bars) for a consistent look at every max-freq window, and the spectrogram uses a scroll-stamp offscreen canvas cache (shift + stamp one row per frame, single blit) instead of redrawing all 100 frames every frame,
- scale dropdown (Lin/Log/Avg Lin/Avg Log) with an Avg dropdown (1/5/10/20/30s): Average modes show the rolling mean of the last X seconds in the frequency spectrum only (recomputed once per second) and the axis scale is explicit per option — Avg Lin for a linear spectrum plot, Avg Log for a log one; the spectrogram always shows the live time-frequency view with the same axis scale, recording to WAV (native) or MP3 (lamejs CDN, default format) with format dropdown, live mic monitor (ScriptProcessorNode passthrough, gain 0.7), input/output device selection (`enumerateDevices`, `setSinkId`) persisted to localStorage (`waSpectrumInput` / `waSpectrumOutput`) and restored on load — compact icon-labelled selects (mic/speaker SVG with `title` tooltips, smaller `.device-select` styling), input volume slider (0–8x gain via `MAX_INPUT_GAIN = 8`, persisted as `waSpectrumInputGain` and restored at load; mic → `inputGain` → analyser/recording/monitor so the volume affects analysis, monitor and recording alike; a limiter (`createDynamicsCompressor`, threshold -3 dB / ratio 20, consts `COMPRESSOR_THRESHOLD_DB` etc.) sits between `inputGain` and the analyser so the >100% range stays visible without clipping artifacts or any signal offset — silence stays silent; `inputGain → recProcessor` is connected once via a `recProcessorConnected` flag, fixing a double-connect on device switches), per-chart Maximize icon button (SVG expand icon, Fullscreen API) overlaid on the canvas (`canvas-wrap` wrapper) that swaps to a minimize icon + tooltip while in fullscreen (CSS `:fullscreen` swap + `fullscreenchange` title update), with canvas resize on the fullscreen promise resolution + delayed 100ms pass + `fullscreenchange` (covers the event-fires-before-layout race), a window `resize` listener, and a draw-loop self-heal that realigns canvas bitmaps with CSS size every frame while sampling, and a spectrogram color-mode button (Colors: Teal, or the classic rainbow/"jet" thermal colormap — Rainbow default; both use a precomputed 256-entry color table, and switching rebuilds the cached spectrogram).
- The controls bar is compact: state toggles are icon + short-label buttons (`.icon-btn`: 1.8rem tall, SVG + text like Osc/Window/Smooth/Colors/Hi-Res/Rec/Mon) with state details in `title` tooltips (JS sets `title` instead of `textContent`); Start/Stop button and scope-scale button keep short text ("Start"/"Stop", "Lin"/"Log"/"Comp"); selects use short option labels (Lin/Log/Avg Lin/Avg Log, Full/24k/…, MP3/WAV) with tighter padding/font and `gap: 0.35rem` between controls; "Avg:" label replaced by a clock icon. `favicon.png` is referenced via `<link rel="icon">`.
- All toggle/select settings persist to localStorage (`waSpectrumOscShow`, `waSpectrumScale`, `waSpectrumAvg`, `waSpectrumWindow`, `waSpectrumSmooth`, `waSpectrumColors`, `waSpectrumMaxFreq`, `waSpectrumAlgo`, `waSpectrumRecFormat`, `waSpectrumBandFreq`, `waSpectrumVuMode` (mode+scale combined, `mode`/`mode_full`), `waSpectrumFsLandscapeOsc` / `waSpectrumFsLandscapeSpec` / `waSpectrumFsLandscapeSpecGram`), saved in each control's listener and restored on load with the UI mirrored (button active classes, tooltips, select values, oscilloscope visibility + scale label) — the session-only Rec/Monitor/Start buttons are never persisted.
- The spectrum curve is normalized to the canvas height (`vScale = HEIGHT / 255`), so the 0..255 amplitude range fills the canvas at any size and matches the (already normalized) amplitude axis labels; a `ResizeObserver` on the three canvases syncs bitmaps on any element size change in addition to the `resize`/fullscreen listeners.
- The page is a full-height flex column (`body: 100dvh`, `main-container: height 100%` + flex column): header and controls take natural height, chart containers (`flex: 1 1 0`, `min-height: 0`, also flex columns) split all remaining vertical space into exactly equal shares, so the oscilloscope joins an even three-way split when shown (leveled graphs); labels are `nowrap` + ellipsis so their height is uniform; the oscilloscope bitmap is resized synchronously via `handleResize()` when toggled, and its trace is clamped to `OSCILLOSCOPE_SAMPLES` samples so large `fftSize` windows can't read past the time buffer. The oscilloscope also has a standing-wave mode: while a stable dominant frequency is present (FFT argmax over the last 4096 ring-buffer samples, parabolic interpolation, EMA-smoothed, 5% drift gate held ~0.2 s — consts `SCOPE_LOCK_MIN_FREQ`/`SCOPE_LOCK_MAX_FREQ`/`SCOPE_MIN_RMS`/`SCOPE_FREQ_EMA_ALPHA`/`SCOPE_FREQ_STABLE_RATIO`/`SCOPE_LOCK_FRAMES`/`SCOPE_LOCK_RELEASE_FRAMES`), the trace reads the ring buffer one period behind the newest sample with linear interpolation, so a steady tone renders as a frozen standing wave (smoothly released back to scrolling after ~0.5 s of drift or silence); `ensureRecGraph()` is now connected unconditionally at `startAudio` so the ring buffer is always fed. Canvas bitmaps stay in sync via the window `resize` listener and draw-loop self-heal.
- Charts are reactive: all resize paths (window `resize`, `ResizeObserver`, fullscreen change, fullscreen settle) funnel through `handleResize()` (rAF-coalesced to one pass per animation frame), which resizes bitmaps and calls `redrawCharts()` — a render from the last captured frame (`lastLiveData`) that works even while the AudioContext is suspended, so charts track the window live instead of going blank. `drawSpectrum(pushFrame)` / `drawSpectrogram(liveData, pushFrame)` gate history pushes (spectrogram rows, average history) to live frames only; redraws reuse the cached spectrogram canvas or rebuild it when its size changed.
