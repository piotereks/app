Hugo Theme M10c Formatting Guide (Mixed: Definitions + Rendered Examples)

This document provides a comprehensive guide to the formatting options supported by the hugo-theme-m10c, combining both definitions and rendered examples for clarity.

1. Headings

Headings are created using # symbols. The number of # symbols determines the heading level.

Definition:

# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6

Rendered Example:

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

2. Paragraphs

Paragraphs are created by writing text on a new line. Leave a blank line between paragraphs.

Definition:

This is a paragraph.

This is another paragraph.

Rendered Example:

This is a paragraph.

This is another paragraph.

3. Blockquotes

Blockquotes are created using the > symbol.

Definition:

> This is a blockquote.

Rendered Example:

This is a blockquote.

4. Lists

Unordered Lists

Unordered lists use -, *, or + followed by a space.

Definition:

- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2

Rendered Example:

  • Item 1
  • Item 2
    • Subitem 2.1
    • Subitem 2.2

Ordered Lists

Ordered lists use numbers followed by a period and a space.

Definition:

1. First item
2. Second item
   1. Subitem 2.1
   2. Subitem 2.2

Rendered Example:

  1. First item
  2. Second item
    1. Subitem 2.1
    2. Subitem 2.2

5. Code Blocks

Inline Code

Inline code is created using backticks `.

Definition:

This is `inline code`.

Rendered Example:

This is inline code.

Code Fences

6. Emphasis

Bold Text

Bold text is created using ** or __.

Definition:

**This is bold text**

Rendered Example:

This is bold text

Italic Text

Italic text is created using * or _.

Definition:

*This is italic text*

Rendered Example:

This is italic text

Bold and Italic Text

Bold and italic text is created using *** or ___.

Definition:

***This is bold and italic text***

Rendered Example:

This is bold and italic text

7. Links

Links are created using [text](URL).

Definition:

[Hugo](https://gohugo.io/)

Rendered Example:

Hugo

8. Images

Images are created using ![alt text](image URL).

Definition:

![Hugo Logo](https://gohugo.io/images/hugo-logo.png)

9. Horizontal Rules

Horizontal rules are created using three or more -, *, or _.

Definition:

---

Rendered Example:

10. Tables

Tables are created using pipes | and dashes -.

Definition:

| Header 1 | Header 2 |
|----------|----------|
| Cell 1   | Cell 2   |
| Cell 3   | Cell 4   |

Rendered Example:

Header 1Header 2
Cell 1Cell 2
Cell 3Cell 4

11. Strikethrough

Strikethrough text is created using ~~.

Definition:

~~This is strikethrough text~~

Rendered Example:

This is strikethrough text

12. Footnotes

Footnotes are created using [^1].

Definition:

This is a sentence with a footnote.[^1]

[^1]: This is the footnote text.

Rendered Example:

This is a sentence with a footnote.1

13. Definition Lists

Definition lists are created by writing a term followed by a colon and its definition.

Definition:

Term 1
: Definition 1

Term 2
: Definition 2

Rendered Example:

Term 1
Definition 1
Term 2
Definition 2

14. Task Lists

Task lists are created using - [ ] for unchecked tasks and - [x] for checked tasks.

Definition:

- [ ] Task 1
- [x] Task 2

Rendered Example:

  • Task 1
  • Task 2

15. Highlighting

Highlight text using ==.

Definition:

This is ==highlighted text==.

Rendered Example:

This is ==highlighted text==.

16. Quotes in Text

Quotes in text are created using double quotes " or single quotes '.

Definition:

This is a "quoted text".

Rendered Example:

This is a “quoted text”.

For more details, refer to the hugo-theme-m10c documentation.
