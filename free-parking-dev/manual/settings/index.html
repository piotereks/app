Settings

The Settings screen lets you personalise the Free Parking Monitor app and get support.

Navigate to Settings by clicking ⚙️ Settings in the header from any screen.

Sections

App Info

Shows the current app version and a brief description of the application.

Color Vision Mode

Adjust the indicator colours (progress bars, status colours) for your colour vision needs.

Eight modes are available:

ModeDescription
Normal (default)Standard green / orange / red palette
ProtanProtanopia / Protanomaly – reduced red sensitivity; uses yellow/amber + blue
DeutanDeuteranopia / Deuteranomaly – green/red confusion; uses blue/orange/purple
TritanTritanopia / Tritanomaly – blue/yellow confusion; uses green/magenta/amber
AchromAchromatopsia (monochromacy) – strong grayscale with monotonic luminance
HiConHigh contrast – crisp tones for low-vision users
LowVisLow vision – highly saturated palette (AMD, diabetic retinopathy)
CataractsCataracts – cooler, higher-contrast tones

How to Select

  • Click any mode button. The active mode is highlighted with a coloured border.
  • Your selection is saved automatically in your browser (key: parking_cb_mode).
  • The colour change takes effect immediately on the Dashboard and Statistics chart.

Compatibility with Theme

All color vision modes work with both Light and Dark themes – each mode has optimised colour variants for both backgrounds.

Feedback & Support

  • Browser user-agent string

Icon shownCurrent modeNext mode on click

System mode automatically follows your operating system’s dark/light preference and updates in real time if you change the OS setting.

Your theme choice is saved in localStorage under the key parking_theme.
